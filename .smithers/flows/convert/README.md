# The convert flow: Effect TypeScript to Effeck

The converter behind effeck.dev's Convert button and `/convert` on smithers.sh/effeck/effeck. The contract is the product spec (`~/Smithers-Ops/Launch/2026-10-19/effeck/app-spec.md`, "The converter" and "`flows/convert/`"):

1. Validate, with no model: refuse `not_effect` unless the source imports from `"effect"`, and `too_large` over 8 KiB.
2. Admit through guest chat's reservation pool.
3. One model call with `prompt.md` as the system prompt.
4. Compile the answer with the converter's compile worker, `packages/converter-worker`: `effeck --noEmit`, no network, one CPU, 512 MiB, 10 s. The program never runs.
5. Return `{state, effeck, diagnostics, effeckVersion, refusal, receipt}`, persisted before the reply.

Smithers runs steps 1, 2, 3 and 5 and calls the worker for step 4. This directory holds the Effeck-owned parts:

| File | What it is |
| --- | --- |
| `prompt.md` | The system prompt. Generated by `build-prompt.mjs` from `instructions/app.md`'s cheat sheet and `examples/` only; never edit it by hand. |
| `golden/NN-name/input.ts`, `expected.effeck` | 20 cases. Case 1 is the hero on effeck.dev. Every input compiles as Effect 4 TypeScript, and every expected output compiles with effeck 0.0.1. |
| `examples/NN-name/input.ts`, `expected.effeck` | 10 worked pairs, separate from all 20 gate cases. Covers the cheat sheet's errors, contracts, services, layers, recovery, retry, timeout, concurrency and provision, plus schemas, methods, fibers, resources and native boundaries. |
| `score.mjs` | Compiles every golden and example expected output with the pinned worker. Exits 1 if any fails. |
| `check-heldout.mjs` | Rejects golden input or output source in examples or prompt code blocks, including copies inside larger blocks. Ignores whitespace and comments between tokens, preserves literal contents, and compares source instead of names. Runs in docs/tools `check:content` and before scoring. |
| `build-prompt.mjs` | Writes `prompt.md`; `--check` fails when it is stale. |

```sh
node .smithers/flows/convert/build-prompt.mjs --check
node .smithers/flows/convert/check-heldout.mjs
node --test .smithers/flows/convert/check-heldout.test.mjs
node .smithers/flows/convert/score.mjs --worker http://localhost:8080   # or in-process on Linux after packages/converter-worker/test/setup-project.sh
```
