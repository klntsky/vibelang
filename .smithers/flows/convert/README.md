# The convert flow: Effect TypeScript to VibeLang

The converter turns one Effect TypeScript file into VibeLang:

1. Validate, with no model: refuse `not_effect` unless the source imports from `"effect"`, and `too_large` over 8 KiB.
2. Admit the request within the visitor's daily limit.
3. One model call with `prompt.md` as the system prompt.
4. Compile the answer with `vibelang --noEmit`. Compilation is required; a hosted compile service is not implemented.
5. Return `{state, vibelang, diagnostics, vibelangVersion, refusal, receipt}`, persisted before the reply.

This directory holds the prompt, the test cases and their checks:

| File | What it is |
| --- | --- |
| `prompt.md` | The system prompt. Generated by `build-prompt.mjs` from `instructions/app.md`'s cheat sheet and `examples/` only; never edit it by hand. |
| `golden/NN-name/input.ts`, `expected.vibe` | 20 cases. Case 1 is the hero example in `docs/site/converter/hero.json`. Every input compiles as Effect 4 TypeScript, and every expected output compiles with vibelang 0.0.1. |
| `examples/NN-name/input.ts`, `expected.vibe` | 10 worked pairs, separate from all 20 gate cases. Covers the cheat sheet's errors, contracts, services, layers, recovery, retry, timeout, concurrency and provision, plus schemas, methods, fibers, resources and native boundaries. |
| `check-heldout.mjs` | Rejects golden input or output source in examples or prompt code blocks, including copies inside larger blocks. Ignores whitespace and comments between tokens, preserves literal contents, and compares source instead of names. Runs in docs/tools `check:content` and before scoring. |
| `build-prompt.mjs` | Writes `prompt.md`; `--check` fails when it is stale. |

```sh
node .smithers/flows/convert/build-prompt.mjs --check
node .smithers/flows/convert/check-heldout.mjs
node --test .smithers/flows/convert/check-heldout.test.mjs
```

## Not built yet

- The flow declaration that runs the steps above.
- The model gate. Once the flow runs, score the model's output for each golden input: compile it locally, and pass when at least 16 of 20 compile with case 1 among them. Results are cached for up to 30 days against the same model, prompt, compiler and dependency digests. All 20 golden cases, including the hero, are held out of the prompt. Prompt examples come only from `examples/`.
- `docs/site/converter/hero.json` is regenerated from the flow's own output for case 1's input, and must stay `compiled`.
